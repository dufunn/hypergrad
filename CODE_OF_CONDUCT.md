# Code of conduct

HyperGrad follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Be respectful, specific, and constructive. Discuss the work rather than the person. Welcome contributors with different levels of experience, protect applicant privacy, and avoid posting personal recruiting information in issues or examples.

Unacceptable behavior includes harassment, discrimination, doxxing, publishing another person's job-search data, sexualized content, threats, or sustained disruption.

## Enforcement

For conduct concerns, use a private GitHub Security Advisory when public discussion would expose personal information. Repository maintainers may edit or remove content and temporarily or permanently restrict participation when necessary.
